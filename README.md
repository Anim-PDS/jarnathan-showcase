# Jarnathan

**A personal AI assistant project focused on local-first operation, privacy, reliability, and user control.**

This is Jarnathan’s public showcase: a place to follow its development, ask questions, and share ideas. The application’s source code remains private.

[Join the conversation](https://github.com/Anim-PDS/jarnathan-showcase/discussions) · [Ask a question or share an idea](https://github.com/Anim-PDS/jarnathan-showcase/discussions/new)

## What I’m building

I’m exploring how a personal AI assistant can be useful in everyday life while giving its user clear control over their information and the actions it takes.

The project’s goals include:

- Making local operation a central part of the experience.
- Keeping personal information under the user’s control.
- Making assistant actions understandable and deliberate.
- Building reliable recovery and maintenance tools.

These are development goals, not promises of finished features.

## Current status

Jarnathan is actively being developed. There is no public release or download available through this showcase yet.

This public space is for selected progress updates and community feedback. It contains no application source code or personal runtime data.
